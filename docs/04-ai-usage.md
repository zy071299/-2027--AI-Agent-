# AI 使用说明

## AI 辅助范围

使用 Codex 协助梳理题目与验收要求、撰写设计和实施计划，并生成 Go CLI、合成资料、自动化测试、运行示例及交付文档。Codex 协助排查 Windows PowerShell 的 UTF-8 读取问题和单文档输入为空的问题，并根据真实模型输出补充引用提示词、测试和评估记录。

## 个人贡献

- 确定 Go CLI 与 DeepSeek 方案，审阅模型决策、工具执行和引用校验的设计。
- 设计并添加 D03 差旅报销适用规则及检索标签，用同一问题验证模型能从报告冲突转为补查、读取 D03 并依据 D02 回答 15 天。
- 完成 DeepSeek 本地联调，复现编码与检索问题，并在修正后重跑对照、保存 Trace。

## 验证结果
- 离线验收覆盖明确答案、文档冲突、资料外问题、相似改写、上下文追问和工具失败。文档替换测试验证答案、引用和补查动作随资料变化。
- 真实 DeepSeek 对照使用同一报销问题。仅提供 D01 时回答 30 天。加入 D02 后，模型读取两份原文、补查适用范围与优先级，最终并列引用两条规定并请求确认。
- 初次真实模型运行给 D01 添加了资料中没有的标题。调整提示词后，两次重跑均使用资料实际提供的文档 ID、日期和原文。具体证据见 [评估记录](03-evaluation.md)。

## 实际用时

2h。
